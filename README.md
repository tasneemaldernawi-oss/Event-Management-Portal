# University Event Management Portal
 # 🏫 Project Overview

The University Event Management Portal is a web-based application designed to manage university events efficiently. The portal allows students to register for events, view participant lists, and navigate event information easily. Each team member contributes to a specific module while collaborating on integration, styling, and responsiveness.

## ⚙️ Core Features
* Registration Module
  HTML form for event registration
  

* Display & Table Module
   Dynamic participant tables
   Styled with Bootstrap table classes

* Styling & Branding Module
    Custom CSS for fonts, colors, spacing, and buttons 
    University logo and event banners
* Layout & Responsiveness Module

     Flexbox layouts for responsiveness
     Header, footer, sidebar, main content area
     Mobile-friendly design with media queries or Bootstrap grid

* Navigation & UX Module

    Navigation bar: Home, Events, Register, Contact

# 🛠️ Technologies Used

* HTML5 – Structure and content
* CSS3 / Bootstrap 5 – Styling and responsiveness
* JavaScript – Dynamic tables, sorting/filtering, UX enhancements
